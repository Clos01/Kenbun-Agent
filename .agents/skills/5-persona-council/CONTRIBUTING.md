# Contributing

Useful contributions are welcome.

Good issues include:

- Installation problems
- Platform compatibility notes
- Output-quality examples
- Documentation confusion
- Reproducible bugs
- Additional platform requests

Please include:

- Skill version
- Platform and version
- Installation method
- Reproduction steps
- Expected behavior
- Actual behavior
- Sanitized prompt/output with private information removed

Please do not submit prompts or examples containing secrets, client data, credentials, financial records, regulated data, or private internal material.

For feature requests, describe the decision type and why the current five-lens process does not handle it well.
