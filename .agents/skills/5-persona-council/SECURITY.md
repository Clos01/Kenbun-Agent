# Security and Privacy

This repository contains a reusable AI skill file. It does not include executable code, network calls, telemetry, or credential handling.

Your AI platform may still send prompt content to its model provider. Review the privacy policy and data-handling settings of the platform where you run the skill.

Do not paste:

- Secrets or API keys
- Passwords or credentials
- Private client data
- Regulated legal, medical, financial, or employment records
- Sensitive internal strategy that should not leave your environment

To report a security or privacy concern, open a GitHub issue with a sanitized description. Do not include secrets in the issue.
