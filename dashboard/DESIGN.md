## Overview

Architectural Minimalism meets Journalistic Gravitas. The UI evokes a
premium matte finish, prioritizing legibility and historical weight.

## 🌌 The Observatory Components

The Kenbun dashboard employs the Heritage design language within the **Observatory** (GalaxyMap) interface to track the live agent swarm:
- **Galaxy Map (`GalaxyMap.tsx`)**: The macro-view of the codebase structure.
- **Node Collision-Free Labels**: Text labels that avoid overlapping to maintain legibility.
- **Pulsing Focus Rings**: Highlights the current execution target of the Orchestrator with smooth micro-animations.
- **SVE Inspector**: An interactive right-side panel used to trigger and review Sovereign Verification Engine (SVE) codebase audits in real-time.
