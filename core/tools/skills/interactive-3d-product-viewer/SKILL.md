# interactive-3d-product-viewer

A WebGL-powered interactive module for rendering 3D products. Features include OrbitControls (zoom/pan/rotate), dynamic environmental lighting, and clickable 3D hotspot annotations to showcase product details.

## Execution Directives

1. **3D Implementation**: Render 3D products using Three.js and React Three Fiber.
2. **Controls**: Implement OrbitControls to allow users to zoom, pan, and rotate the model.
3. **Lighting & Environment**: Ensure dynamic environmental lighting is applied for high-fidelity 3D visualization.
4. **Hotspots**: Integrate clickable 3D hotspot annotations that display context-aware product details when clicked.
5. **Output Format**: The skill MUST produce a single, self-contained HTML `<artifact>` block utilizing relevant whitelisted CDNs.
6. **Responsiveness**: Canvas should properly resize to fit the visual constraints and device frames from the Visual Observatory.
