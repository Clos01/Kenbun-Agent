# saas-analytics-dashboard

An advanced telemetry and financial metrics dashboard for B2B SaaS. Unlike the generic dashboard skill, this focuses on high data density, interactive charting (time-series, heatmaps, donut charts), and complex data-grid interactions with filtering.

## Execution Directives

1. **Layout & UX**: Focus on high data density. Include complex data-grid interactions with filtering capabilities.
2. **Charts & Visualization**: Provide interactive charting using Recharts, including time-series, heatmaps, and donut charts.
3. **Components**: Build upon Shadcn UI patterns and Tailwind CSS.
4. **Output Format**: The skill MUST produce a single, self-contained HTML `<artifact>` block, utilizing whitelisted CDNs if rendering as a self-contained prototype.
5. **Responsiveness**: Ensure the dashboard adapts seamlessly across the device frames provided by the Visual Observatory.
